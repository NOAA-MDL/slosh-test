The SLOSH model relies on several specific file formats for meteorological
inputs, basin configurations, and output reporting.

Select a format below for format specifications, usage, and examples:

* **[STM File (stm-file)](./stmFile.html):** 6-hourly storm parameter inputs,
  including storm track, central pressure, and radius of maximum winds.
* **[DTA File (dta-file)](./dtaFile.html):** Basin configuration data,
  encompassing topography, bathymetry, barriers, and sub-grid features.

* **[REX File (rex-file) - *Coming Soon*](#):** Time-series snapshots of wind
  and water heights at specific grid cells.
* **[TRK File (trk-file) - *Coming Soon*](#):** 1-hourly interpolated storm
  track data used directly by the parametric wind model.
