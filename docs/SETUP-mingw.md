## MinGW 4.5.0
*From a Cygwin prompt*
```bash
   mkdir -p c:/sys/MinGW/MinGW-4.5.0
   cd c:/sys/MinGW/MinGW-4.5.0
```

Get a copy of 'getMinGW-450.sh', either from:
   [getMinGW-450.sh](../../master/docs/util/getMinGW-450.sh)

Or, if you've cloned the slosh repo, it's in:
    ~/save/slosh/docs/util/getMinGW-450.sh

```bash
   cp ~/save/slosh/docs/util/getMinGW-450.sh .
   ./getMinGW-450.sh go
```
