Some quick directions on how to modify the ???dta files to use/not use the
56 foot threshold (vs 35 foot) and/or the x-filter smooths.

In the first row, the following holds...

Column 12 -- '$' => elliptical (ebasins), '+' => hyperbolic (hbasins)
Column 13+14 -- '$' indicates closed island (periodic boundary condition)
             -- '2$' indicates MSY basin
             -- '1$' has "initialize dry cells"
Column 15 -- smoothing options...
            + smooth every timestep,    = also call smpt2g
            # smooth every 5 timestep,  ! also call smpt2g
            % smooth every 10 timestep, @ also call smpt2g
            & smooth every 20 timestep
            * smooth every 30 timestep, ^ also call smpt2g
Column 16 -- '+' Output options (J-I), default is (I-J)
Column 17 -- '&' is southern hemisphere
          -- '$' indicates XOKE = 'X'
Column 18 -- '+' indicates no flooding or over-topping of barriers
Column 19 -- '+' no 1d flow allowed
Column 20 -- '+' allow between 35 and 56 feet to flood
Column 21 -- '+' use x-filter smoothing method (HCRT=0.5).
             '-' use x-filter smoothing method (HCRT=0.1).
             '@' use x-filter smoothing method (HCRT=0.2).
             '#' use x-filter smoothing method (HCRT=0.3).
             '$' use x-filter smoothing method (HCRT=0.4).
             '*' x filter exclusion of cells by Epsilon. (HCRT=0.1)
             '%' x filter exclusion of cells by Epsilon. (HCRT=0.2)
             '^' x filter exclusion of cells by Epsilon. (HCRT=0.3)
             '&' x filter exclusion of cells by Epsilon. (HCRT=0.4)
             '=' x filter exclusion of cells by Epsilon. (HCRT=0.5)
